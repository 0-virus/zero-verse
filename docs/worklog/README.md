# worklog

마일스톤별 개발 로그. `docs/PRD.md`의 마일스톤(M0~M10) 단위로 파일을 만든다.

- **파일 규칙**: `M{n}-<slug>.md` (예: `M1-auth.md`) — 마일스톤당 1개. 파일을 매번 새로 만들지 말고 내부에 timestamp 항목을 append 한다.
- **추적 여부**: 상위 `docs/`는 `.gitignore`로 무시되지만, 이 디렉터리는 `!docs/worklog/` 예외로 **git 추적된다**(PR diff에 로그 포함).
- **고정 섹션**: `[계획]`(Codex) → `[개발 기록]`(Claude, 시각별 append) → `[이슈·결정]` → `[리뷰]`(Codex) → `[머지]`.
- **목적**: 코드 리뷰 시 "로그 ↔ 실제 작업 일치" 검증, 이후 마일스톤의 참고 자료.

상세 프로세스는 루트 [`AGENTS.md`](../../AGENTS.md)의 "개발 프로세스" 섹션 참조.
